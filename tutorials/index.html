🕹 Learn to code by making games

Make real games

Playful tutorials for people who have never programmed before. Each one builds a complete, cute little game from an empty screen, one small step at a time, right here in your browser.

  • 🌱 No experience needed
  • 💻 Nothing to install
  • 🎯 Challenges that check themselves

How the tutorials work

✍️Edit real codeEvery step has the game's actual code. Change anything, and new lines glow so you can spot them.
⚡See it instantlyPress Run and the game plays right next to your code, powered by the real js-game-zero engine.
🎯Challenges check themselvesLittle tasks watch your running game and cheer when you've done it. Hints are there if you're stuck.
⬇️Keep what you makeDownload your game as a folder that runs in the js-game-zero sandbox or with the jgz tool.

Start with Firefly Flash if you've never coded before. Each tutorial takes about one and a half to two hours, and your progress is saved in this browser.
