Set it up once

                
You need Bun. JS Game Zero and its jgz tool come from npm.

                
git clone https://github.com/Leaf-Learning/jgz-tutorial.git
cd jgz-tutorial
bun install
bunx playwright install chromium

                
Building one by hand? bun run new frog_feast "Frog Feast" sets up the files.
